Sample Superstore Sales Dashboard

Project Overview

This project analyzes Sample Superstore sales data using interactive dashboards to understand business performance and identify useful insights.

Tools Used

- Microsoft Excel
- Microsoft Power BI (if applicable)

Dashboard Pages

1. Sales Analysis: Total sales and sales trends.
2. Quantity Analysis: Quantity sold and product demand.
3. Discount Analysis: Discount patterns across products and categories.
4. Profit Analysis: Profitability by category, region and product.

Key Performance Indicators (KPIs)

- Total Sales
- Total Quantity
- Average Discount
- Total Profit

Project Objectives

- Analyze sales and profit performance.
- Identify high-performing categories and regions.
- Understand discount patterns.
- Support data-driven business decisions.
